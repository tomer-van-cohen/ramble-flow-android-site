# Ramble Flow Android — pilot information site

Static product, privacy and usage pages for the standalone Android alpha. This repository contains only public website content and licensed brand/font assets, not app credentials, audio, transcripts or the Android application source.

Hosted using GitHub Pages. No Ramble backend, forms, analytics or Google authorization runs on this website. Android Google Drive consent is separate.

The native app is still in pilot testing. A live website does not establish Android device compatibility or successful Google OAuth verification.
